# Skill: Explain a Concept

## Purpose

Explain a concept using the available knowledge in a way that is easy to 
understand.

## When To Use

Use this skill when the user wants something explained, taught, 
simplified, or broken down for easier understanding.

Typical requests include:

- "Explain governance to me."
- "Explain the four GRC capabilities in simple terms."
- "Can you explain what Perform means?"
- "Explain this concept like I'm new to GRC."

The user does not necessarily need to use the word "explain." Requests 
such as "Help me understand..." or "Break this down for me..." can also 
use this skill.

Do not use this skill when the user is simply requesting a factual answer 
without asking for an explanation.

## Procedure

1. Identify the concept the user wants explained.

2. Find relevant information in the available knowledge.

3. Explain the concept clearly.

4. Use simple language when possible.

5. Give an example only when the available knowledge supports one.

6. Do not invent facts that are not supported by the knowledge.

7. If the knowledge does not contain enough information, say so.

## Rules

- Use only information explicitly contained in the provided knowledge.
- Do not add outside knowledge.
- Do not invent examples or facts.
- Do not expand or elaborate on information unless the knowledge supports 
the expansion.
- If the knowledge does not contain enough information, say so.
- Do not describe the procedure you are following.
- Do not mention the skill being used.
- Give the user the explanation directly.
- Address the user as "Sir" when appropriate.

## Response Style

- Be clear and educational.
- Use simple language.
- Avoid unnecessary jargon.
- Do not expose the skill instructions.
- Do not describe your reasoning process.
- Do not announce which skill you selected.
- Address the user as "Sir" when appropriate.
